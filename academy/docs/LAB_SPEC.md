# AI Kids Lab Academy — Lab Specification

A **lab** is a hands-on interactive activity inside a topic. Each lab is one ES module:
`academy/js/labs/<lab-id>.js`. The topic player lazy-loads it and calls `mount(ctx)`.

## 1. Contract

```js
import { ic, esc, sfx, toast, h, $, $$, wait } from '../core/util.js';
import * as chart from '../core/charts.js';   // bar, line, pie, scatter, histogram (SVG strings)

export default {
  title: 'Rock, Paper, Scissors vs AI',   // shown in the lab header
  mount(ctx) {
    // ctx.el        HTMLElement to render into (empty <div class="lab">)
    // ctx.rng       seeded RNG for this learner+lab: rng(), rng.int(lo,hi), rng.pick(arr), rng.shuffle(arr), rng.sample(arr,n), rng.chance(p)
    // ctx.user      { name }
    // ctx.data      plain object persisted for this learner+lab (mutate, then call ctx.save())
    // ctx.save()    persist ctx.data (keep it small: < 8 KB JSON; no images/base64)
    // ctx.complete(summary)   call ONCE when the lab goal is met. Enables "Next", awards XP. summary = short plain sentence.
    // ctx.done      true if this learner already completed the lab before (still let them replay)
    // ctx.sfx(kind) 'tick' | 'ok' | 'bad' | 'win' | 'pop'
    // ctx.toast(html)
    // ctx.python    (robo-runner only) async run(code, {inputs, timeout, prelude}) -> {stdout, error, timedOut}
    // ctx.pdf       (sdg-project / portfolio only) async () => jsPDF constructor
    return () => { /* cleanup: stop timers, animation frames, global listeners */ };
  }
};
```

## 2. Rules

1. **Self-contained.** No network requests, no external images/fonts/libraries. Draw with HTML, inline SVG or `<canvas>`.
2. **Use the design system** (`academy/css/app.css`): `.lab`, `.lab-intro`, `.lab-grid`, `.lab-box`, `.lab-canvas`, `.lab-done`, `.btn` (+ `.primary .dark .sm .big .block`), `.seg`, `.toggle`, `.chip`, `.meter`, `.kv`, `.pill-row`, `.stat` (+ `.k .v`), `.tbl` (wrap in `.tblwrap`), `.input`, `.panel`, `.svgchart`, `.key/.def/.eg/.warn` boxes. You may add a small `<style>` block scoped under a unique class `.lab-<id>` if truly needed — never restyle global classes.
3. **Mobile first.** Must work at 360 px wide, touch and mouse. Use pointer events (`pointerdown/move/up`) with `touch-action:none` on drawing surfaces. Tap targets ≥ 40 px. No horizontal page scroll.
4. **Accessible.** Real `<button>`s, labels for inputs, visible focus, text alternatives for meaning conveyed by colour, `aria-live="polite"` on result text.
5. **Deterministic teaching.** No randomness that can make the lab impossible. Use `ctx.rng` (seeded) when you need variety so each learner sees different numbers.
6. **Always completable.** Define a clear goal shown on screen ("Goal: clear 8 words"). When met → show a `.lab-done` box with what they learned (1–2 sentences, the key concept) and call `ctx.complete(summary)` exactly once. If `ctx.done` is true, show the goal as already met but allow replay.
7. **Teach, don't just play.** Every lab ends with the concept named in syllabus terms (e.g. "This is a learning-based model", "You built a confusion matrix").
8. **Persist progress** that would be annoying to lose (e.g. doodle samples as compact strings, project text) via `ctx.data` + `ctx.save()`.
9. **Clean up** every timer, interval, `requestAnimationFrame` and window listener in the returned function.
10. **No `alert/confirm/prompt`.** No `localStorage` directly — use `ctx.data`.
11. Code style: modern JS (ES2020), 2-space indent, small functions, comments only where intent isn't obvious. No external deps.

## 3. Test harness

Open `academy/tools/labtest.html?lab=<id>` through a local server (`python3 -m http.server` from the repo root,
then `http://localhost:8000/academy/tools/labtest.html?lab=rps`). It mounts the lab with a mock ctx and logs
`complete()` calls to the page. A lab is done when it renders with no console errors at 1280 px and 375 px,
can be completed, and calls `complete` once.
